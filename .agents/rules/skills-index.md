## How To Use This Map

1. **Discovery**: match the task description in your prompt against the
   `Description` column, then load the skill at the `Canonical Path`.
2. **Governance**: the `Governing Rule` is the Layer 2 rule that constrains
   how the skill must be applied. Load it before using the skill.
3. **Status**: `WIP` skills are upstream work-in-progress and are
   indexed for discovery, but are not production-approved.

This file is generated — run `python3 scripts/generate-skills-index.py`
after adding, renaming or removing a skill.
